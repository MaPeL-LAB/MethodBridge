# Roadmap

## Gate 1

Eligibility, benchmark review, compact-model bake-off, prompt-only comparison, conditional adapter training, GGUF conversion, quantization comparison, profiler, hosting, and submission.

## Post-Gate 1

User research, controlled learning studies, optional local knowledge packs, independently validated African-language pilots, additional disciplines, better desktop UX, and institutional deployment policies.

Retrieval, cloud inference, and a broad application platform are not Gate 1 priorities.
