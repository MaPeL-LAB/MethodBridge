# MethodBridge Local model release

**Release state:** no final model has been selected, approved, or published.

The repository retains `Qwen/Qwen3-1.7B` with `Q5_K_M` only as a documentary
first-test hypothesis. It is not the current model release, empirical winner,
approved quantization, or submission artifact.

A final model card will be generated by `scripts/prepare_model_release.py` only
after all of the following are true:

- `config/model_selection_state.yml` records `human_approved_finalist`;
- the exact source revision and GGUF SHA-256 are recorded;
- licence and redistribution review is complete;
- qualified semantic adjudication is complete;
- independent quantization comparison is complete;
- official reference-laptop profiling is complete;
- clean credential-free download and load testing is complete;
- public claims have been reviewed;
- `config/release_authorization.yml` contains attributable human authorization.

Until then, this directory contains documentation only. Model weights must not be
committed to Git.
