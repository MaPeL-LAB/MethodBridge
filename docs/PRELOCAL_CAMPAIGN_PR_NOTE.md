# Pre-local empirical campaign handoff

This branch prepares MethodBridge for the first legitimate local model-engineering campaign while preserving the restored fail-closed evidence boundary.

It does not claim that any candidate model or quantization has been empirically selected. It adds machine-readable campaign, run-evidence, semantic-review, public-claims, release-authorization, and handoff contracts so that local work can produce reviewable evidence without promoting simulations, documentary estimates, or automated keyword proxies into model or submission claims.

The document may be removed after the pull request is merged if its content is fully represented by the permanent handoff and governance documents.
