# Demo video storyboard — evidence gated

**Status:** draft; do not record final narration until the final artifact and
reference profile exist.

## Scene 1 — problem and intended user

Explain the offline research-methods support problem without claiming that
MethodBridge has already improved educational or research outcomes.

## Scene 2 — repository and evidence boundary

Show:

- frozen benchmark identity;
- exact candidate registry;
- simulation-proxy versus real-model evidence classes;
- hardware classification;
- blocked model-selection state.

## Scene 3 — actual local model output

This scene may be recorded only after a digest-bound GGUF successfully runs through
the pinned `llama.cpp` path. Display the exact model SHA-256 and label the host as
`simulation_only` unless it is a qualifying reference host.

Do not show invented tokens per second, RAM, TTFT, accuracy, retention,
perplexity, or quantization conclusions.

## Scene 4 — semantic and human review

Show the privacy-preserving review record, failed or inconclusive cases, limits,
and the fact that automated keyword overlap is not expert judgment.

## Scene 5 — reference profile and release

Record only after official participant-mode evidence exists. Use values read from
the immutable verified run record, not handwritten narration. Show the exact GGUF
digest, official profiler commit, host attestation, repeated runs, limitations,
and human approval.

## Required final review

```text
[ ] Every numerical claim has an immutable evidence reference.
[ ] The shown GGUF digest matches the hosted artifact.
[ ] The host classification is visible.
[ ] Simulation evidence is not described as official evidence.
[ ] No raw private prompt, response, credential, or local path is shown.
[ ] Final model, quantization, prompts, release, and submission have human approval.
```
