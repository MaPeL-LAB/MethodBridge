# Contributing

Use feature branches after the bootstrap baseline. Every change should include tests, documentation, provenance, and an honest status update. Model experiments must record the exact model revision, licence, toolchain commits, seed, prompt/template version, quantization, context, threads, hardware, and raw measurements.

Do not submit private data, credentials, proprietary textbook content, model weights, or unreviewed generated curriculum. Pull requests that change protected decisions require accountable human review.
