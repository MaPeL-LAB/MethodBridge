# Risks and unintended effects

| Risk | Control |
|---|---|
| False confidence | explicit uncertainty, human authority, critical-error tests |
| Incorrect methodological advice | human rubrics, held-out suite, escalation |
| Fabricated citation | refusal and citation-integrity tests |
| Clinical drift | out-of-scope and safety tests |
| Academic misconduct | integrity policy and test cases |
| Privacy leakage | synthetic repository data; local-only real material |
| Benchmark overfitting | held-out freeze and public-prompt exclusion |
| Catastrophic forgetting | general-retention gate |
| Memory/thermal failure | profiler and internal headroom target |
| Tokenistic African positioning | load-bearing offline constraints and explicit diversity |
